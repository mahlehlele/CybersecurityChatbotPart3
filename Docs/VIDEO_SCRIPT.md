# Video script

Use your own voice. Upload the video as Unlisted on YouTube.

1. Introduce yourself and state your student number.
2. Show the GitHub repository.
3. Show at least 6 meaningful commits.
4. Show the three releases: v3.0, v3.1, v3.2.
5. Show the GitHub Actions green tick.
6. Open the project in Visual Studio 2022.
7. Run the WPF application.
8. Show the voice greeting playing and ASCII art displaying.
9. Type: `My name is Asemahle`.
10. Type: `I am worried about phishing` and explain sentiment detection.
11. Type: `tell me more` and explain conversation flow.
12. Type `Give me a phishing tip` twice to show random responses.
13. Type: `Add task - Review privacy settings`.
14. Type: `Yes, remind me in 3 days`.
15. Show the task in the Task Assistant tab.
16. Open `tasks.json` and show the task was saved.
17. Mark the task complete and show `IsComplete` updates in `tasks.json`.
18. Delete a task and show it is removed from `tasks.json`.
19. Start the quiz and answer several questions.
20. Show immediate feedback and final score.
21. Demonstrate NLP with three different phrases:
    - `Remind me to update my password tomorrow`
    - `Add a task to enable 2FA`
    - `Quiz me`
22. Type: `show activity log`.
23. Show the latest 10 entries and Show More.
24. Explain these code files:
    - `TaskStorageHelper.cs`
    - `TaskManager.cs`
    - `QuizManager.cs`
    - `ActivityLogger.cs`
    - `ChatBot.cs`
